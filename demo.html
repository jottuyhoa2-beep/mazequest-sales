    How to use it

    1. Pick a theme and difficulty. Easy mazes are wide and short. Hard mazes are tight and long.
    2. Generate your book. Flip through the preview to check every page.
    3. Download the PDF. Print it at home, or upload it to KDP. The page size you picked is the exact size of the PDF — Letter is 8.5 x 11 inches, A4 is 8.27 x 11.69 inches.
    4. Check the answer key. The last page shows every maze solution and every hidden word.

    Tip: make a new book for each child. The shuffle button gives you a fresh book with the same settings, so no two kids get the same puzzles.
